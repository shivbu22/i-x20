# Shivam Yadav Portfolio

Multi-page, game-inspired founder portfolio for Shivam "Shiv" Yadav.

## Stack

- React + TypeScript + Vite
- GSAP + ScrollTrigger for transition choreography
- Three.js for the interactive orbital AI core

## Run locally

```bash
npm install
npm run dev
```

Routes: `/` (Launch), `/missions`, `/profile`, and `/contact`.

Before launch, add Shiv's direct email and replace the mission `EXPLORE` placeholders with verified project URLs when available.
